# → anote PHONE_ENCRYPTION_KEY: _________________________

nano .env
# Ajuste EXATAMENTE estas linhas (deixe o resto do exemplo):
#
#   ENV=development
#   LLM_PROVIDER=ollama
#   LLM_MODEL=qwen2.5-math:1.5b-instruct
#   OLLAMA_BASE_URL=http://127.0.0.1:11434
#   ADMIN_API_KEY=<cole o 1º openssl>
#   AUDIT_PHONE_SALT=<cole o 2º openssl>
#   PHONE_ENCRYPTION_KEY=<cole a chave Fernet>
#   LANGCHAIN_TRACING_V2=false
#   BILLING_ENFORCE_SUBSCRIPTION=false
#
# Por que ENV=development no 1º ensaio:
#   com ENV=production a API EXIGE chaves fortes; development libera o 1º teste.
#   (Quando for produção de verdade, volte ENV=production com as 3 chaves ok.)

Erros comuns (já vistos / previstos no 24.04):
1) "python3.11: command not found"
   → use python3 (Passo 2 e 4). NÃO instale 3.11 neste guia.

2) "No such file or directory" no cp do pendrive
   → rode ls /mnt/usb e ls /mnt/usb/Projects e ajuste o caminho.

3) "externally-managed-environment"
   → source .venv/bin/activate antes do pip.

4) pip / torch demora ou usa muita RAM
   → normal; feche outros serviços; espere; 8GB RAM é mínimo.

5) ollama: connection refused
   → sudo systemctl enable --now ollama
   → ollama list

6) uvicorn sobe e cai falando AUDIT_PHONE_SALT / PHONE_ENCRYPTION_KEY
   → .env com ENV=development e as 3 chaves do Passo 6 (sem texto "defina_").

7) indexação sem arquivos
   → coloque PDF em data/materials/ antes do run_indexing.py
