6) ARQUIVO .env (segredos)
================================================================================
cd ~/deepEdu
source .venv/bin/activate
cp .env.example .env
chmod 600 .env

Gere as chaves (copie cada saída para a folha):

openssl rand -hex 32
# ADMIN_API_KEY = ________________________________

openssl rand -hex 32
# AUDIT_PHONE_SALT = ______________________________

python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
# PHONE_ENCRYPTION_KEY = __________________________

Editar:

nano .env

Confira / ajuste estas linhas (as outras podem ficar como estão por enquanto):

ENV=development
LLM_PROVIDER=huggingface
LLM_MODEL=amadeusai/Amadeus-Verbo-FI-Qwen2.5-0.5B-PT-BR-Instruct
LLM_TOKENIZER_ID=amadeusai/Amadeus-Verbo-FI-Qwen2.5-0.5B-PT-BR-Instruct
LLM_DEVICE_MAP=auto
ADMIN_API_KEY=(cole a chave gerada)
AUDIT_PHONE_SALT=(cole a chave gerada)
PHONE_ENCRYPTION_KEY=(cole a chave Fernet)
LANGCHAIN_TRACING_V2=false
BILLING_ENFORCE_SUBSCRIPTION=false

Salvar no nano: Ctrl+O  → Enter
Sair: Ctrl+X

================================================================================
ERROS COMUNS → SOLUÇÃO
================================================================================
ping falha
  → cabo/rede/DNS; sem net não instala nada

externally-managed-environment
  → source .venv/bin/activate  e use o pip DO venv

python3.11: command not found
  → use python3 (é o certo no 24.04)

Unable to locate package gh
  → use o bloco curl do passo 3A ou a Opção B (copiar pasta)

gh: 404 / repo private
  → gh auth login de novo; autorize no celular

erro Hugging Face / baixar modelo
  → confira internet; rode de novo: bash scripts/install_hf_model.sh
  → disco: df -h

CUDA / GPU
  → sem GPU use LLM_DEVICE_MAP=auto (CPU). Fica mais lento, mas funciona.

Nenhum material encontrado
  → coloque PDF em data/materials/ e rode run_indexing.py

curl /health falha
  → confira se uvicorn está rodando no outro terminal
  → source .venv/bin/activate antes do uvicorn
  → espere o modelo carregar na 1ª vez

pip demora / trava em torch
  → normal na 1ª vez; aguarde (pode passar de 10–20 min)

disco cheio / pouca RAM
  → df -h   e   free -h
  → modelo 0.5B + torch precisam de espaço e memória
