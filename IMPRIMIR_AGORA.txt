6) ARQUIVO .env (segredos)
================================================================================
cd ~/deepEdu
source .venv/bin/activate
cp .env.example .env
chmod 600 .env

Gere as chaves (copie cada saída para a folha):

openssl rand -hex 32
# ADMIN_API_KEY = ________________________________

Editar:

nano .env

Confira / ajuste estas linhas (as outras podem ficar como estão por enquanto):

ENV=development
LLM_PROVIDER=ollama
LLM_MODEL=qwen2.5-math:1.5b-instruct
LLM_TOKENIZER_ID=Qwen/Qwen2.5-Math-1.5B-Instruct

================================================================================
ERROS COMUNS → SOLUÇÃO
================================================================================
ping falha
  → cabo/rede/DNS; sem net não instala nada

externally-managed-environment
  → source .venv/bin/activate  e use o pip DO venv

python3.11: command not found
  → use python3 (é o certo no 24.04)

Unable to locate package gh
  → use o bloco curl do passo 3A ou a Opção B (copiar pasta)

gh: 404 / repo private
  → gh auth login de novo; autorize no celular

ollama: connection refused
  → sudo systemctl enable --now ollama
  → systemctl status ollama

Nenhum material encontrado
  → coloque PDF em data/materials/ e rode run_indexing.py

curl /health falha
  → confira se uvicorn está rodando no outro terminal
  → source .venv/bin/activate antes do uvicorn

pip demora / trava em torch
  → normal na 1ª vez; aguarde (pode passar de 10–20 min)

disco cheio
  → df -h   e libere espaço antes de pip/ollama
